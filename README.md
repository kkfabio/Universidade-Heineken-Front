# 🍺 Universidade Heineken — Front-End

> Plataforma de Capacitação e Gestão de Aprendizado (LMS) desenvolvida como um **projeto de Residência Tecnológica**, tendo como empresa parceira a **Motiron Tech**[span_0](start_span)[span_0](end_span). A escolha da Heineken como modelo de negócio e identidade visual foi uma decisão estratégica da nossa equipe de desenvolvimento, e o sistema é integrado a um ecossistema de **Back-End desenvolvido em Java com Spring Boot**.

Este repositório contém a aplicação corporativa de **Front-End** da Universidade Heineken. A plataforma foi projetada para otimizar jornadas de aprendizado corporativo, centralizando cursos, trilhas de conhecimento e dashboards de desempenho para colaboradores e gestores[span_1](start_span)[span_1](end_span).

---

## 🏫 Residência Tecnológica

Este projeto foi desenvolvido dentro do ecossistema da **Residência Tecnológica**, uma iniciativa do Porto Digital focada em conectar talentos em formação com desafios reais de engenharia de software e design de interfaces[span_2](start_span)[span_2](end_span).
* **Empresa Parceira:** Motiron Tech[span_3](start_span)[span_3](end_span)
* **Modelo de Negócio:** A escolha da marca Heineken como tema e modelo da plataforma foi idealizada inteiramente pela nossa equipe para simular um cenário corporativo robusto e realista.
* **Objetivo:** Criar um ambiente educacional corporativo (LMS) escalável, performático e intuitivo baseado em necessidades corporativas autênticas da Heineken[span_4](start_span)[span_4](end_span).

---

## ⚙️ Arquitetura do Sistema

Para garantir a robustez necessária em uma plataforma de grande escala, o ecossistema foi dividido em duas camadas independentes:
* **Front-End (Este repositório):** Desenvolvido em Next.js, TypeScript e Tailwind CSS para proporcionar uma experiência de usuário (UX) fluida, rápida e responsiva[span_5](start_span)[span_5](end_span).
* **Back-End:** Construído em **Java com Spring Boot**, fornecendo uma API REST estável, segura e escalável para o gerenciamento de regras de negócio, persistência de dados e segurança.

---

## 🚀 Tecnologias Utilizadas (Front-End)

A aplicação utiliza o ecossistema de desenvolvimento web mais moderno do mercado para garantir uma interface rápida, segura, escalável e de fácil manutenção[span_6](start_span)[span_6](end_span):

* **[Next.js](https://nextjs.org/)** — Framework React para produção, utilizando *App Router*, *Server-Side Rendering (SSR)* e *Static Site Generation (SSG)*[span_7](start_span)[span_7](end_span).
* **[TypeScript](https://www.typescriptlang.org/)** — Tipagem estática para maior segurança no código, prevenção de bugs em tempo de compilação e melhor experiência de desenvolvimento[span_8](start_span)[span_8](end_span).
* **[Tailwind CSS](https://tailwindcss.com/)** — Framework CSS utilitário para design ágil, responsividade nativa e consistência com a identidade visual da Heineken[span_9](start_span)[span_9](end_span).
* **[Supabase (Auth & Client)](https://supabase.com/)** — Integração com infraestrutura de Backend-as-a-Service para autenticação segura de usuários e persistência/sincronização de dados em tempo real[span_10](start_span)[span_10](end_span).
* **[Lucide React / Heroicons](https://lucide.dev/)** — Conjunto de ícones vetoriais limpos e consistentes[span_11](start_span)[span_11](end_span).
* **[ESLint & Prettier](https://eslint.org/)** — Padronização de qualidade e formatação de código[span_12](start_span)[span_12](end_span).

## 🎨 Arquitetura de Design & UI

A interface reflete rigorosamente a identidade visual e os princípios de UI da Heineken[span_13](start_span)[span_13](end_span):
* **Paleta de Cores:** Uso estratégico do verde icônico da marca (`#21713B`) combinado com tons neutros elegantes, garantindo alto contraste e acessibilidade[span_14](start_span)[span_14](end_span).
* **Componentização:** Interface baseada em componentes reutilizáveis e atômicos, facilitando a escalabilidade[span_15](start_span)[span_15](end_span).
* **Design Responsivo:** Otimização completa para múltiplos dispositivos (Smartphones, Tablets e Desktops), permitindo que os colaboradores estudem em qualquer lugar[span_16](start_span)[span_16](end_span).
